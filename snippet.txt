1. NON-NEGOTIABLE RULE
==================================================

Jangan membuat mock architecture yang terlihat production-ready tetapi sebenarnya tidak berfungsi.

Jangan membuat:
- fake database
- fake authentication yang dianggap production
- fake payment yang dianggap payment gateway
- fake OAuth yang dianggap sudah terhubung
- fake QR validation client-side
- hardcoded event data
- hardcoded ticket data
- hardcoded homepage content
- hardcoded Supabase secrets
- localhost dependency
- placeholder API yang dianggap selesai

Jika sebuah integration belum mempunyai credential:

Implementasikan architecture dan adapter-nya dengan benar.

Gunakan:

DEMO MODE

tetapi beri tanda jelas:

DEMO MODE

Jangan pernah menyamarkan demo sebagai production integration.

65. IMPORTANT IMPLEMENTATION RULE
==================================================

Jangan mencoba mengerjakan semuanya secara asal dalam satu file atau satu komponen.

Jika existing project sudah mempunyai component:

REUSE IT.

Jika existing page sudah bagus:

DO NOT REDESIGN IT.

Jika existing animation sudah bagus:

PRESERVE IT.

Jika existing asset sudah tersedia:

REUSE IT.

buat typed interface.
